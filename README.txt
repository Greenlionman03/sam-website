DELIVERABLE 2 — INTERACTIVE WEBSITE PROTOTYPE

Files:
- index.html: Home/about page
- gallery.html: Art gallery and character entries
- commissions.html: Commission information table and inquiry form
- style.css: External CSS used by all pages
- script.js: Theme toggle and client-side form validation

HOW TO TEST LOCALLY
1. Extract this folder.
2. Open index.html in Chrome or Firefox.
3. Use the navigation to visit all three pages.
4. Test the theme button on each page.
5. Open commissions.html and test empty fields, invalid email, and a valid sample form.
6. The form is a prototype only. It validates locally and does not send/store submissions.

BEFORE PUBLISHING
- Replace artwork placeholders with your own image files and accurate descriptive alt text.
- Replace the general commission rows with your actual commission types, prices, terms, and availability. These were not provided in the earlier project sources.
- Add your actual social/profile links.
- Publish all five files together so the relative links work.
- Run WAVE, Lighthouse Accessibility, or axe DevTools on the published Form page (commissions.html) and Table page (commissions.html contains the table). Save screenshots of the actual results; no audit has been run or fabricated here.
- Create the required 1–2 page PDF report using the real tool results and remediation notes.

ACCESSIBILITY NOTES
- Semantic landmarks, skip link, heading hierarchy, table caption and scoped headers, explicit labels, required fields, status live region, keyboard focus styling, responsive layout, and reduced-motion handling are included.
- Automated scans and manual keyboard testing are still required. The prototype cannot claim WCAG conformance without testing.
